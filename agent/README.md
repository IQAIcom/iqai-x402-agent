This app hosts the IQ_x402 agent built with ADK. It uses a wallet-enabled axios client (x402-axios) to pay for server endpoints when required. The agent fetches the server’s `/api/get-prices` on greeting to tell users what paid calls cost, and then uses tools like `GET_AGENT_INFO`, `GET_AGENT_STATS`, and `GET_TOP_AGENTS` through the server. Provide `WALLET_PRIVATE_KEY` (and optionally OpenRouter keys) in `.env`.
